BioAI_SimEngine 仿生AI基因进化仿真引擎
 
项目简介
 
BioAI_SimEngine 是一套基于 C++ + OpenGL 开发的离线虚拟生物AI进化仿真引擎，集成基因工程演算、仿生数字躯体控制、720°三维全景渲染、真实生态模拟、AI自主决策与闭环进化五大核心能力。
 
系统形成完整演化闭环：
 生态环境动态变化  →  AI环境感知与动作决策  →  仿生躯体运动交互  →  基因组自主变异进化  →  躯体性状同步更新  →  反向适配生态 ，模拟虚拟生命持续演化过程。
 
本项目全程本地离线运行，无云端依赖，模块化架构设计，支持分层迭代扩展，可用于虚拟生命仿真、数字人仿生、AI自主进化研究、三维生态场景模拟等场景。
 
 
 
一、环境与编译要求
 
1. 开发环境
 
- 编译器：Visual Studio 2022
- 运行平台：Windows 10 / Windows 11 (X64)
- 编译模式：推荐  Release x64 
 
2. 第三方依赖库（全部离线）
 
依赖库 作用 使用方式 
GLAD OpenGL 函数加载器 源码引入  glad.c  
GLFW3 窗口创建、事件、渲染上下文 静态库  glfw3.lib  
GLM 数学库（矩阵、向量、坐标变换） 仅头文件，直接引用 
 
说明：所有依赖均为本地静态/头文件形式，无需联网。

三、功能说明
 
1. 基因工程系统
 
- 定义标准 DNA 四种碱基： A / T / C / G 
- 基因组划分多段性状基因：骨骼、神经、运动能力
- 支持AI 自主随机变异，自动迭代基因版本
- 基因权重实时映射躯体物理参数，实现「基因决定外形与性能」
 
2. 仿生躯体控制系统
 
- 内置 16 组可动关节，支持全身姿态连续运动
- 躯体缩放、反应速度由基因组动态驱动
- 接收 AI 动作指令，逐帧更新关节角度
 
3. AI 自主决策模块
 
- 实时读取生态环境数据，自主生成躯体动作序列
- 定时触发基因进化流程，驱动虚拟生命迭代升级
 
4. 仿生生态模拟
 
- 模拟周期性环境波动（模拟昼夜、气候变化）
- 全局生态时序管理，定时触发进化逻辑
- 环境状态直接影响 AI 行为模式，形成生态闭环
 
5. 720°全景三维渲染
 
- 三轴自由旋转相机（Yaw / Pitch / Roll），实现全角度无死角观察
- 基础 3D 场景搭建：地面、全景边界环境
- 固定管线 OpenGL 渲染，运行轻量化、帧率稳定
 
 
 
四、快速编译 & 运行步骤
 
1. 使用 VS2022 新建空 C++ 项目
2. 按照上方目录结构，在项目内创建  Core 、 Render  文件夹
3. 将对应  .h  /  .cpp  源码文件放入对应目录
4. 配置项目属性：- 附加包含目录：添加  GLM 、 GLAD  头文件路径
- 附加库目录：添加  GLFW3.lib  所在路径
- 链接器 → 输入：附加依赖项填写  glfw3.lib 
5. 将  glad.c  加入项目源码列表
6. 切换解决方案平台为 x64，编译模式选择 Release
7. 点击「本地Windows调试器」运行程序
 
 
 
五、运行效果
 
1. 窗口启动后自动加载虚拟生态场景与仿生躯体
2. 相机持续三轴旋转，720°全景展示整个虚拟空间
3. 躯体根据环境数据自主运动，姿态实时变化
4. 每 25 秒自动触发一次基因变异：- 基因组版本号自增
- 躯体大小、动作反应速度自动微调
5. 环境持续周期性波动，与 AI、躯体、基因形成联动闭环
 
 
 
六、版本迭代升级路线（规划）
 
本项目采用模块化设计，可按阶段平滑升级，不改动原有核心架构：
 
阶段一：高精度骨骼数字人（1~3天）
 
- 引入  Assimp  模型加载库
- 支持 FBX / OBJ 标准人形模型导入
- 重构层级骨骼绑定系统，替换简易方块躯体
- 实现真实人体骨骼运动逻辑
 
阶段二：PBR 写实渲染 + 自由视角（3~7天）
 
- 升级为 OpenGL 3.3 Core 可编程着色器
- 实现 PBR 金属粗糙度写实渲染、实时光照、雾效
- 相机增加鼠标操控，支持手动 720°自由环视
- 昼夜光影与生态系统深度联动
 
阶段三：接入本地大模型，实现真实AI自进化（7~15天）
 
- 对接本地离线大模型（如 Qwen2 量化版）
- AI 具备自我分析、算法优化、代码生成能力
- 增加受控联网检索、插件热加载、本地编译测试
- 实现 AI 自主编写插件、迭代自身逻辑
 
阶段四：深度基因工程 + 种群生态（15~30天）
 
- 拓展 DNA / 氨基酸序列、显隐性遗传、器官性状模拟
- 接入  Bullet  物理引擎，实现全身动力学、碰撞、受力
- 支持多生物个体、种群演化、繁衍模拟
- 完善季节、气象、物质能量循环，构建完整虚拟生态圈

八、常见问题
 
1. 编译提示找不到 glfw3.lib
→ 检查库目录配置，确认平台为 x64，库文件版本匹配。
2. 运行窗口黑屏、无画面
→ 检查  glad.c  是否正确加入项目，OpenGL 上下文是否正常初始化。
3. 程序闪退
→ 优先切换至 Release x64 模式，关闭多余调试钩子，检查依赖完整性。
